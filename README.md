# NCM 格式转换工具

批量解密网易云音乐 `.ncm` 加密格式，转换为无损音频文件（`.flac` / `.mp3` / `.wav`）。

## 功能特性

- 🎵 **批量转换**：选择文件夹，一键批量解密所有 `.ncm` 文件
- 📁 **自动整理**：转换后的文件统一输出到源文件夹下的 `音乐/` 子目录
- 📋 **实时日志**：图形界面显示处理进度和成功/失败状态
- 🎨 **现代 UI**：基于 CustomTkinter，支持深色/浅色主题
- 🔄 **冲突处理**：同名文件自动添加 `_copy` 后缀，不会覆盖
- ⚡ **多线程**：转换过程不阻塞界面

## 环境要求

- Windows 系统
- Python 3.8+（如需直接运行源码）
- 依赖库：`customtkinter`

## 安装依赖

```powershell
pip install customtkinter
```

## 使用方法

### 方式一：直接运行源码

1. 确保 `NCM转mp3拖一拖.exe` 和 `ncm格式转化v2.0.py` 在同一目录
2. 运行脚本：
   ```powershell
   python ncm格式转化v2.0.py
   ```
3. 点击「选择文件夹」，选择包含 `.ncm` 文件的文件夹
4. 点击「开始处理」，等待转换完成
5. 转换后的文件保存在源文件夹的 `音乐/` 子目录中

### 方式二：打包为 EXE

使用 PyInstaller 打包：

```powershell
pyinstaller -F -w ncm格式转化v2.0.py
```

将生成的 EXE 与 `NCM转mp3拖一拖.exe` 放在同一目录即可运行。

## 注意事项

- `NCM转mp3拖一拖.exe` 必须与主程序放在同一目录，否则无法运行
- 源文件夹路径请避免包含特殊字符
- 转换后的音频质量取决于原始 `.ncm` 文件的编码质量
- 本工具仅供学习交流使用，请支持正版音乐
